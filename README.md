# Darwish Portfolio Showcase

Create a premium, world-class portfolio website named "Darwish" with the following specifications:

**OVERALL DESIGN PHILOSOPHY:**
- Ultra-modern, minimalist design with sophisticated animations
- Clean, professional aesthetic with generous white space
- Smooth, buttery animations throughout (60fps performance)
- Mobile-first, fully responsive across all devices
- Dark/Light mode toggle capability
- Glassmorphism and subtle gradient effects

**COLOR SCHEME:**
- Primary: Deep navy blue (#0F172A) or sophisticated charcoal (#1E293B)
- Accent: Vibrant gradient (e.g., cyan to purple: #06B6D4 to #8B5CF6)
- Background: Clean white (#FFFFFF) with soft gray sections (#F8FAFC)
- Text: Dark slate (#0F172A) with medium gray for secondary text (#64748B)
- Use subtle color transitions on hover states

**SECTIONS TO INCLUDE:**

1. **Hero Section:**
   - Full viewport height with animated gradient background
   - Large, bold name "Darwish" with animated fade-in
   - Tagline/role (e.g., "Creative Developer & Designer")
   - Animated call-to-action buttons
   - Smooth scroll indicator animation
   - Particle effects or geometric shapes in background

2. **About Section:**
   - Professional photo with hover effects
   - Compelling bio with animated text reveal
   - Skills displayed as animated progress bars or icon grid
   - Personal stats or achievements counter animation
   - Download resume button

3. **Services/Expertise Section:**
   - 3-6 service cards with hover animations
   - Icons with smooth scaling effects
   - Brief descriptions of each service
   - Staggered fade-in animations on scroll

4. **Portfolio/Projects Section:**
   - Grid or masonry layout with filtering options
   - High-quality project thumbnails
   - Smooth hover effects revealing project details
   - Modal/overlay for detailed project views
   - "View Project" and "Source Code" buttons
   - Categories: Web Development, UI/UX, Apps, etc.

5. **Testimonials Section:**
   - Carousel with smooth transitions
   - Client photos and company logos
   - Star ratings with animation
   - Auto-play with manual controls

6. **Contact Section:**
   - Working contact form with validation
   - Social media icons with bounce animations
   - Email and location info
   - Interactive map (optional)
   - Success/error message animations

**NAVIGATION:**
- Sticky header with blur background on scroll
- Smooth scroll to sections
- Active section highlighting
- Mobile hamburger menu with smooth slide animation
- Logo/name on the left, nav links on the right

**ANIMATIONS TO IMPLEMENT:**
- Page load: Smooth fade-in sequence
- Scroll animations: Elements fade/slide in when visible (use Intersection Observer)
- Hover effects: Scale, glow, color transitions
- Button animations: Ripple effects, gradient shifts
- Parallax scrolling for background elements
- Typing animation for hero tagline
- Number counting animation for stats
- Cursor follow effect or custom cursor (optional)

**TECHNICAL REQUIREMENTS:**
- Built with React and TypeScript
- Tailwind CSS for styling
- Framer Motion for advanced animations
- Lucide React for icons
- Fully responsive (mobile, tablet, desktop)
- Optimized images (lazy loading)
- SEO-friendly structure
- Fast loading times
- Smooth transitions between all states

**INTERACTIVE ELEMENTS:**
- Animated hover states on all clickable items
- Form validation with helpful error messages
- Smooth page transitions
- Loading animations
- Scroll progress indicator
- Back to top button with smooth scroll

**TYPOGRAPHY:**
- Headings: Modern sans-serif (Inter, Poppins, or Montserrat)
- Body: Clean, readable font (Inter or Open Sans)
- Hierarchy: Clear distinction between h1, h2, h3
- Proper line height and letter spacing

**FINAL TOUCHES:**
- Footer with social links and copyright
- Micro-interactions throughout
- Consistent spacing using Tailwind's spacing scale
- Accessibility considerations (ARIA labels, keyboard navigation)
- Professional imagery and icons
- Subtle shadows and depth effects

Please ensure every element has smooth transitions, the color palette is cohesive, and the overall experience feels premium and polished. The website should leave a lasting impression and showcase professional excellence.
